 - Cadastro de Carros

Primeiro projeto desenvolvido em Python.

**Objetivo**
A ideia é fazer um cadastro simples de carros, informando o nome, a marca e o ano do veículo.

**O que o programa faz?**
- Informar o nome do carro
- Informar a marca
- Informar o ano
- Classificar o carro como novo ou usado

**Linguagem**
- Python

**Como executar**
É necessário ter o Python instalado no computador.

Depois, é só abrir o terminal na pasta do projeto e digitar:
python carros.py
